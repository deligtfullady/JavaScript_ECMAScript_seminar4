# Практическая работа: Асинхронность в JavaScript (ECMAScript)
**Урок 4. Асинхронность в JavaScript**

## Цель работы
Освоить работу с асинхронными операциями в современном JavaScript: `fetch`, промисы, `async/await`, `setTimeout`. Научиться обрабатывать успешные ответы и ошибки при работе с API, а также выполнять отложенные действия в DOM.

---

## Структура проекта

- `index.html` — HTML‑страница с интерфейсом и кнопками для запуска примеров, а также блоком вывода логов.
- `script.js` — реализация функций `getUserData`, `saveUserData`, `changeStyleDelayed` и обработчиков событий.
- `README.md` — данный файл с описанием заданий, эталонами решений и инструкциями по запуску.

> Для локальной демонстрации в проекте реализована эмуляция API (`mockFetch`). Чтобы использовать реальный сервер, см. раздел «Переход на реальный API».

---

## Задания

### Задание 1. Получение данных о пользователе

**Функция:** `getUserData(userId)`  
**Цель:** реализовать асинхронную функцию для получения данных пользователя с удалённого сервера.

**Требования:**
1. Принимает `userId` (число или строка) как аргумент.
2. Использует `fetch` (или эмуляцию) для запроса к URL вида `https://api.example.com/users/${userId}`.
3. Если ответ успешен (`response.ok === true`), извлекает JSON через `response.json()` и возвращает объект данных.
4. Если ответ неуспешен, отклоняет промис с сообщением об ошибке (например, `"User not found"`).
5. Обрабатывает возможные сетевые ошибки и также отклоняет промис с понятным сообщением.
